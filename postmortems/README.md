# 事故复盘制度

准入（三项同时满足才写）：隐蔽 / 系统性 / 重新发现代价高。
不满足的压缩成一行带日期的规则写进 AGENTS.md。

纪律：注意力放在"系统为什么允许这个错误发生"；防护措施必须能表述成
"某个具体的东西会在这种情况下变红"，写不出的进"经验教训"不计入产出；
每次事故同时变成一条回归用例并记录来源。

## 模板
# <主题>
准入：□隐蔽 □系统性 □重新发现代价高
## 摘要（三十秒） / ## 时间线 / ## 根因
## 为什么所有安全网都没有拦住   ← 逐条列你以为会拦住它的东西及失效方式
## 新增的防护措施               ← 每条必须是会变红的东西，附链接
- [ ] 已验证：引入回归 → 观察变红 → 已回退
## 经验教训                     ← "以后注意"类内容放这里
